# Keyboard shortcuts

On Windows and Linux use **Ctrl** where macOS uses **⌘**.

## Anywhere

| Shortcut | Action |
|---|---|
| **⌘T** | New request tab |
| **⌘↵** | Send the active request |
| **⌘S** | Save the active request |
| **⌘O** | Import |
| **Esc** | Close the open dialog |

## Request editor

| Shortcut | Action |
|---|---|
| **↵** in the URL bar | Send (HTTP), or Connect / Invoke (WebSocket, SSE, gRPC) |
| **⌘↵** in the message composer | Send the message on an open WebSocket or gRPC stream |
| Middle-click a tab | Close it |
| **Ctrl+Space** in a GraphQL query | Show completions |

## Code editors (bodies, scripts, responses)

| Shortcut | Action |
|---|---|
| **⌘F** | Find (the panel also offers replace in editable editors) |
| **⌘/** | Toggle comment (scripts) |
| **⌘Z** / **⌘⇧Z** | Undo / redo |
| **Tab** / **⇧Tab** | Indent / outdent |
